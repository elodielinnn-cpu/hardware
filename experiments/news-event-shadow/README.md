# 新闻事实抽取对照试验

`Compare structured news events` 是手动触发的只读试验。输入是一次成功的 `Update reviewed news` 运行号和该次生成数据的完整提交 SHA。脚本核对快照与运行包时间和代码版本。可选填上次试验的运行号，复用正文、提示词和知识库版本均未变的结构化结果。结果产物包含 comparison.csv 和 comparison.json。

- 旧版使用该批实际应用过的首页决定。两种试验版共用结构化抽取和证据校验。修复＋行业观察版最多追加 3 条去重后的观察新闻。
- 结构化事实每篇最多 5 个，正文编号引用。程序核对字段、原文位置与证据、知识库 ID、对象状态、准入路径和去重。引文匹配不能自动证明原文语义支持所有字段，仍需人工复核。
- 每轮最多选 12 篇，按 6／4／2 给已有准入、漏选复查、行业观察候选，空位互补。正文最多传 12,000 字符，报告标明截断。沿用 50,000 输入与 3,000 输出 token 的调用上限，实际完成数可能低于选定数。未完成候选继续留在报告，不能计为移除。模型错误、HTTP 状态和用量单列。若新选稿没有一篇完成结构化抽取，任务标记失败并保留诊断产物。
- 上次通过的事件若本轮来源暂时缺席，在 30 天窗口内继续参与比较；已更新文本则重新判断。同一事件可按有事实日期的结构化键或已有跨来源正文重复检测合并。纯改写、跨语种、无日期且不共享原句的事件仍可能漏去重。
- 原抓取阶段已抛弃且没有正文快照的文章无法抽取。队列中可见但未进入旧快照的文章单列，旧版只有未展示事实，没有逐条旧版拒绝理由。

首次回放可用运行 `45928405745` 与提交 `b5ea0f790930257c06a05d9e69acaf75978a5189`。本地也可运行 `node experiments/news-event-shadow/run.mjs SNAPSHOT.js QUEUE.json OUTPUT.json [PRIOR.json]`。缺少本地模型密钥时仅验证输入、候选分组、旧版基线与报告，所有未抽取项标为未完成。规则边界测试运行 `node experiments/news-event-shadow/test.mjs`。

正式验收应在本版冻结后，从后续至少一个完整自然周逐日保存快照和运行包，按时间顺序回放并传入前一份试验结果。人工逐条标注新增、移除和抽样未入选事件，记录直接业务漏选数、观察稿认可数／复核总数，以及低价值误入、传闻误标、计划误标数。观察目标至少 80%，同时公布分子和分母。一周验证之前不替换正式流程。
